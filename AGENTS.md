# Project Instructions

## Task completion

- When the user asks to finish or complete an Actum task, ask for completion details before changing its status.
- Useful completion details include the outcome, verification performed, and relevant pull request, commit, issue, or document links.
- If the user already provides sufficient completion details in the same request, do not ask again.
- Record the supplied details in the task's completion note and preserve relevant links when marking the task complete.
